Unity
	can directly drag folders to "project" window to upload assets
	copy and paste by using "ctrl+c -> ctrl v" to copy objects at the current location
	has option to create "empty" as a folder in the hierarchy panel to organize assets
	drag assets from the hierarchy to the project folder to create a preset "prefab"

Unreal
	can directly drag folders to "content drawer" window to upload assets
	copy and paste by using "ctrl+c -> ctrl v" to copy objects at the current location
	has option to create "folder" in the outliner panel to organize assets


Godot
	can directly drag folders to "FileSystem" window to upload assets
	copy and paste by using "ctrl+c -> ctrl shift v" to copy objects at the current location
	use new "scene" as the folder to organize assets hierarchy
	use "packed scene" as preset


Prefab, Blueprint Actor, and Packed Scenes all serve the same purpose in their respective engines. In my build, they all create mesh presets for creators to manage assets more easily. Unity might be the easiest one for creating such presets, while Unreal is the most arduous, as it requires creating a new Blueprint class, separating mesh components in the preview, and then importing meshes one by one. Godot is also relatively easy, but the so-called preset is handled under the logic of scenes. It is still not as easy as Unity, where you can simply click and drag assets into a folder, which may cause management problems if more scenes are involved and the hierarchy is not clearly organized into different folders.


I will probably choose Unity to build such a level. Although Godot and Unreal are also fine for building, the procedures in Unreal take too much time. Godot manages levels and preset “prefabs” all within scenes, which makes them kind of hard to re-catch for clear management. Unity is just the right balanced option to achieve such a goal.
